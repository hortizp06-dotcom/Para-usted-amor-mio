# Para mi princesa 💌

Sitio estático (HTML + CSS + JS). No necesita servidor, base de datos ni pagos.

## Qué subir
Sube TODO el contenido de esta carpeta: `index.html`, `style.css`, `script.js`, `README.md` y la carpeta `assets` (con `favicon.svg` y `images/`).

## Publicar en GitHub Pages (gratis)
1. Entra a https://github.com y crea una cuenta (o inicia sesión).
2. Arriba a la derecha toca **+ → New repository**.
3. Nombre del repositorio: algo neutro como `para-ti` (el nombre aparecerá en el enlace). Elige **Public**.
4. Toca **Create repository**.
5. Toca **uploading an existing file**, arrastra TODOS los archivos y la carpeta `assets` (desde el computador es lo más fácil), y toca **Commit changes**.
6. Ve a **Settings → Pages**. En *Source* elige **Deploy from a branch**, rama **main**, carpeta **/ (root)** y toca **Save**.
7. Espera 1 o 2 minutos y recarga. Arriba aparecerá tu enlace: `https://TU-USUARIO.github.io/NOMBRE-DEL-REPO/`
8. **Vista previa en WhatsApp:** abre `index.html` en GitHub (lápiz ✏️) y cambia en la línea `og:image` las palabras `TU-USUARIO` y `TU-REPO` por los tuyos. Guarda con **Commit changes**. WhatsApp guarda la vista previa en caché: prueba el enlace con un chat contigo mismo antes de enviarlo.
9. Pruébalo en tu celular abriendo el enlace y revisa la música, las fotos y la carta.

## Cambiar cosas después
Todo está al inicio de `script.js`, en la zona **DATOS EDITABLES**: textos, fecha, canción, recuerdos, "cosas que amo" y carta. En GitHub abre el archivo, toca ✏️, edita y guarda con **Commit changes**; se actualiza en 1–2 minutos.

Para cambiar una foto: sube una nueva a `assets/images/` (JPG, ancho ~900 px, menos de 300 KB) con el mismo nombre para reemplazarla, o con otro nombre y cámbialo en `memories`.

## Privacidad
En GitHub Pages gratis el repositorio es público: cualquiera con el enlace (o que encuentre el repo) puede ver las fotos y textos. Alternativa gratuita más privada: Netlify Drop (https://app.netlify.com/drop), arrastras la carpeta y obtienes un enlace difícil de adivinar, sin repositorio público.

## Música
Se usa el reproductor oficial de Spotify (sin alojar archivos de música). Se carga al tocar el botón, porque los navegadores bloquean el autoplay. Con cuenta de Spotify se oye completa; sin cuenta, un fragmento.
